学习机付费日报看板 · 使用说明
════════════════════════════════

■ 在线链接（发给同事即可查看）
  https://zhenggang123.github.io/xuexiji-daily/

■ 看板内容
  双11窗口 10/12–11/11，京东自营官旗+POP官旗 · 讯飞学习机，2026 vs 2025 同窗对比。
  5张核心卡（花费/ROI/UV/CPC/净费G比，均剔品专）+ 日度费用×ROI×净费G比综合图
  + 分推广工具表 + 系列花费结构图 + 型号明细表（容量/版本独立行）。

■ 日常更新（把两张底表发给 Claude 即可，说"更新学习机日报看板"）
  Claude 会执行：
  1. python3 tools/build.py <付费日报明细.xlsx> <明细表-全渠道.xlsx>
  2. git add -A && git commit -m "更新至 X月X日" && git push
  约1分钟后线上生效（浏览器强刷 Cmd+Shift+R）。

■ 临时查看（不走发布）
  直接打开线上页面，用右上角两个上传按钮传当天两张表，仅本次浏览生效。

■ 文件夹职责
  index.html                  线上页面（含内置数据，勿手改）
  tools/dashboard_template.html  页面模板（改样式/逻辑在这里，含 __DATA__ 占位符）
  tools/data2025.json         2025年基线数据（已冻结，勿动）
  tools/build.py              重算+注入脚本

■ 口径备忘
  点击量=UV；花费/ROI/CPC/点击及占比均剔品专（品牌合约广告位，工具表单列不计入合计）；
  ROI=总成交金额÷花费；净费G比=花费÷净GMV（明细表-全渠道，渠道=京东）；
  两年自然日历对齐（10/12起算），累计对齐至今年最新数据日。
